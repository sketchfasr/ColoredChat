# Colored Chat

Standalone BepInEx IL2CPP chat formatting mod.

Press **F6** to open the GUI. In the Presets tab, a note says presets can be used in any lobby. Left-click a number to send it; right-click a number to show its output below the list. The self-copy toggle starts on. Press **F6** or Escape to close the GUI. Preset multi-select and preset spam are removed.

The Custom Colored Chat (+25 mode) tab can be opened in any lobby. The game version reports modded, or the local player's network-data owner is the host (`-2`). When the lobby is server-authoritative, the tab displays a warning and disables sending and spam; unavailable lobby/player data also blocks sends. The tab has an uncapped text box, one primary formatting mode (plain, color, gradient, RGB, font, size, indent, cspace, mspace, voffset, or rotation), and combinable bold, italics, nobr, underline, and strikethrough styles. Font selection uses left/right arrows around a boxed font name; an optional Cycle between fonts button advances to the next font after every sent message. Typing in the focused message box blocks keyboard movement input; clicking elsewhere in the tab exits text entry. Clicking Send while RGB is selected sends the message and enables spam, which sends every 0.05 seconds. **Hide spam for yourself** filters recent messages sent by this mod's spam toggle from your local chat view, while other players' messages remain visible. Rich-text tag support for each formatting option must be confirmed in-game.
